# Mini Jeu Soldat avec Armes (Java)

## Description Générale
Mini Jeu “Soldat avec Armes” est un jeu de combat en console Java où le joueur incarne un soldat et affronte un ennemi contrôlé par l’ordinateur. 
Chaque soldat possède une vie, une position sur le terrain, et peut utiliser différentes armes avec des dégâts spécifiques.

Le joueur peut :
- Avancer ou reculer pour se déplacer sur le terrain.
- Attaquer l’ennemi avec son arme actuelle.
- Changer d’arme pour augmenter ses dégâts.

Le jeu met l’accent sur la stratégie, car le choix de l’arme et le timing de l’attaque peuvent influencer le résultat du combat.

## Armes Disponibles
- **Épée** : 20 dégâts
- **Lance** : 30 dégâts
- **Arc** : 15 dégâts

## Comment Jouer
1. Cloner le repo :  
   `git clone <URL-DU-REPO>`
2. Compiler le fichier Java :  
   `javac src/MiniJeuSoldat.java`
3. Lancer le jeu :  
   `java -cp src MiniJeuSoldat`
